# Phase: Retro

Find the current session directory. Create `notes.md` if it doesn't exist.

Think carefully about the full session — review the conversation history, the spec, plan, and any notes already recorded.

Before writing, ask any questions that seem worth capturing (e.g., anything that felt unclear, decisions that had notable tradeoffs, things that should be done differently next time).

Write a complete session retrospective in `notes.md` covering:

- **Recap** — brief summary of what was built or accomplished
- **Divergences** — what changed from the original plan and why
- **Insights** — key technical or process lessons learned
- **Cost** — total session cost if shown in the UI
- **Efficiency** — observations on what went smoothly or slowly
- **Process improvements** — specific suggestions for future sessions
- **Conversation turns** — approximate total number of back-and-forth exchanges
- **Other highlights** — anything else notable or interesting about the session
